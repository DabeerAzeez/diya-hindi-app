# Lesson A0-07: Gender Suffixes & Agreement Rules


### Quick Summary Rule of Thumb

* **`aa`** = Masculine singular (used for *Main* [if male], *Vo* [he], *Ye* [this/he])
* **`e`** = Masculine plural or formal/casual address (used for *Tum*, *Aap*, *Hum*, *Vo/Ye* [they])
* **`ii`** = Feminine (singular AND plural/respect, whether it's *Main* [if female], *Vo* [she], or a feminine object like *coffee*)
    * In some tenses like past tense, there is `in` ending for feminine plural/formal as well, just not for present tense
