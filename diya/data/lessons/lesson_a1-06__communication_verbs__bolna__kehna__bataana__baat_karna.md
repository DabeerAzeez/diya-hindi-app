# Lesson A1-06: Communication Verbs (Bolna, Kehna, Bataana, Baat Karna)

| **Hindi Verb** | **English Infinitive Verbs** |
| --- | --- |
| **Bolna** | To speak, to talk (one-way) |
| **Kehna** | To say, to state |
| **Bataana** | To tell, to inform |
| **Baat karna** | To talk (two-way), to converse, to chat |
